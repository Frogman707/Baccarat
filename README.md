# 바카라 슈 판독기

**→ https://frogman707.github.io/Baccarat/**

테이블 화면을 읽어 구슬판을 데이터로 바꾸고, 그 테이블의 셔플이 정상인지 검정하는
브라우저 도구입니다. 설치할 것이 없습니다.

## 쓰는 법

1. **화면 공유 시작** 을 누르고, 테이블이 열린 탭을 고릅니다
2. 끝입니다 — 몇 초마다 구슬판을 다시 읽어 새 판이 나오는 대로 들어옵니다

**폰 하나로 볼 때는** 화면 공유가 아예 없습니다(브라우저의 제약입니다). 대신 보면서
캡처만 눌러 두고, 나중에 **사진 여러 장 가져오기** 로 한 번에 넘기세요. 겹치는
캡처는 알아서 같은 슈로 합쳐져 가장 긴 것만 남습니다. 데스크톱에서는 캡처해서
`Ctrl+V` 로 붙여넣어도 됩니다.

## 무엇을 하는 도구인가

바카라를 이기는 도구가 아닙니다. 정직하게 섞인 8덱 슈에서 완벽한 카드 카운터가
얻을 수 있는 우위의 천장은 **판당 +0.0008%** 이고, 그마저도 슈 소진율 75% 이후
368판에 1판꼴로만 나타납니다. 결과만 있는 데이터로 답할 수 있는 진짜 질문은
따로 있습니다 — **이 테이블의 셔플이 실제로 무작위인가.**

그래서 이 페이지가 하는 일은:

- 뱅커 베팅이 손익분기가 되는 지점(51.282%)과 플레이어(50.000%) 사이의 **죽은 구간**
  위에, 이 테이블의 실측값과 95% 신뢰구간을 그립니다
- 17개 순서 통계를 **같은 크기의 시뮬레이션 슈 코퍼스**와 비교합니다
  ("50.68%의 독립시행"과 비교하면 정직한 테이블도 이상으로 나옵니다)
- 다중검정 보정(Benjamini-Hochberg)을 거친 판정을 냅니다
- 지금 표본으로 **탐지 가능한 최소 편향**을 함께 보여줍니다 — "이상 없음"이 아직
  결론이 아닌 경우를 구분하기 위해서입니다

## 개인정보

전부 브라우저 안에서 돕니다. 공유한 화면 영상도, 모은 결과도 어떤 서버로도
전송되지 않고 녹화되지도 않습니다. 수집한 슈는 이 브라우저에만 저장되며,
CSV/JSON 으로 내려받을 수 있습니다.

카지노 사이트에 접속하지 않습니다 — 화면에 이미 떠 있는 그림만 분석하므로
사이트 주소도 로그인 정보도 필요 없습니다.
